About this project

Data science prototype with transparent, reproducible recommendation logic

CareerPilot AI — Job Recommendation & Skill Gap Analyzer

This is a full-featured frontend demonstration that works with bundled, synthetic job data. No real vacancies are claimed. No model training, database, authentication, scraping, or external API requests are required.

Recommendation model

Weighted skill overlap (75%), experience compatibility (15%), and preferred location affinity (10%). Rankings are deterministic and interpretable.

Skill gap model

Compares existing skills to a role's required-skill union. Calculates coverage percentages and prioritizes unmet skills by frequency across roles.

Technology

Single self-contained HTML5, CSS3 and vanilla JavaScript file; localStorage; data export via Blob downloads.

Dataset

32 fictional job postings across 8 data-science-related roles and 6 Indian cities, including remote and hybrid work options.

See the included README.md, methodology, architecture, user guide, and other documentation files for full details. Do not treat synthetic salaries or fictional openings as real-time market information.
